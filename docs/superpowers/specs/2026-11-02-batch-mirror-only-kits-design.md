# 全部镜像与 Only Kits 图层设计

## 目标

- 将当前选中图层的“垂直镜像”按钮替换为“全部镜像”。
- 点击“全部镜像”时，只水平翻转当前画布内全部 `original` 与 `cutout` 图层，并把整批变更记为一次可撤销操作。
- 商品标题以不区分大小写、完整单词方式命中 `kit` 或 `kits` 时，自动创建内容为 `Only Kits` 的文字图层。

## 图层规则

- 已有商品编号时，`Only Kits` 复制编号图层的全部文字样式、宽度、缩放与水平中心。
- `Only Kits` 的顶部位于编号文字实际底部之下，并保留间距，不能遮挡编号。
- 没有商品编号时，`Only Kits` 使用编号图层的默认样式和默认位置。
- `Only Kits` 是独立可编辑图层；刷新已保存画布、自动排版后仍应保留，且不得重复创建。

## 非目标

- 不批量镜像品牌 Logo、文字、衬板或水印。
- 保留现有“水平镜像”按钮对当前选中图层的单图层操作。
- 不改变商品编号的提取规则。

## 实现选择

- 批量镜像使用 reducer 的专用 action，一次生成一个新文档和一条历史记录；不循环派发多次 `COMMIT_LAYER`。
- 标题套件判断放在可单测的纯函数中，匹配 `kit` / `kits` 的英文完整单词。
- `Only Kits` 由编号文字层构造器旁的纯函数创建；位置使用文字测量结果计算，找不到编号时退回编号默认位置。
